# Security policy

## Supported versions

This project is an early preview. Security fixes are applied to the latest code on `main` and the
most recent release, when releases exist. Older snapshots are not supported.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use the repository's **Security** tab
to submit a private vulnerability report. If private reporting is unavailable, email
`devanshsehgal02@gmail.com` with the subject `rewrite-spring-to-helidon security report`.

Include the affected recipe and version, a minimal reproduction, impact, and any suggested
mitigation. Remove credentials, proprietary source, and personal data. You should receive an
acknowledgement within seven days; disclosure timing will be coordinated after the report is
validated and a remediation is available.

Security-relevant reports include transformations that expose an endpoint, weaken authorization,
change validation or transaction behavior, generate unsafe code, or introduce a vulnerable build
dependency.
